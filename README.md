# 2026 글로벌 연수 사전조사 발표자료

## 프로젝트 개요

Learning Technologies France 2026과 네덜란드·프랑스 학교 방문을 위해 조사한 내용을 브라우저에서 열람할 수 있도록 구성한 정적 발표 자료입니다. `index.html`은 핵심 내용을 15장으로 요약하고, `data.html`은 컨퍼런스 세션, 전시 부스, 학교별 조사 및 비교 내용을 146장의 상세 슬라이드로 제공합니다.

이 저장소는 발표 화면과 조사 원본을 함께 보관하는 아카이브입니다. 별도의 서버 애플리케이션, 빌드 과정 또는 데이터베이스는 사용하지 않습니다.

## 주요 기능

- Learning Technologies France 2026 세션·키노트·전시 부스 조사 내용 열람
- 네덜란드와 프랑스의 방문 학교 소개 및 교육 구조 비교
- `index.html`에서 이전·다음 버튼과 방향키 또는 스페이스 바로 15장 요약 자료 탐색
- `data.html`에서 146장 상세 자료의 편집 보기·발표 보기 전환, 키보드 탐색 및 전체 화면 실행
- `data.html`에서 화면 폭과 발표 모드 뷰포트에 맞춘 1280×720 슬라이드 축소 렌더링
- 브라우저의 `contenteditable` 속성을 이용한 화면 내 텍스트 임시 편집
- 상세 발표 자료, 저장소의 조사 원본 및 외부 공동 아카이브로 이동하는 링크 제공

## 기술 스택

- HTML5
- 인라인 CSS
- Vanilla JavaScript
- Google Fonts CDN
- Font Awesome CDN

프레임워크, 패키지 관리자 및 별도 빌드 도구는 사용하지 않습니다.

## 프로젝트 구조

```text
.
├── index.html    # 15장으로 구성된 요약 발표 자료
├── data.html     # 146장으로 구성된 상세 조사·발표 자료
├── image/        # 로컬 이미지 자산 6개(현재 HTML에서 4개 참조)
└── raw_data/     # 조사 원본 및 가공 자료
```

`raw_data/`에는 CSV 10개, XLSX 3개, DOCX 6개, PDF 1개가 들어 있습니다. 이 파일들은 조사 근거를 보관하기 위한 자료이며, 두 HTML 페이지가 실행 중에 직접 읽거나 가공하지는 않습니다.

## 설치 및 실행

별도 의존성 설치는 필요하지 않습니다. 저장소 루트에서 정적 파일 서버를 실행합니다.

```bash
git clone https://github.com/memilmuk82/2025_AIEdutech_Seoul.git
cd 2025_AIEdutech_Seoul
python3 -m http.server 8000
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8000/index.html
```

상세 자료는 요약 자료의 링크를 이용하거나 `http://localhost:8000/data.html`로 직접 열 수 있습니다. Google Fonts와 Font Awesome 아이콘은 CDN에서 불러오므로 해당 스타일을 온전히 표시하려면 인터넷 연결이 필요합니다.

## 환경 변수

필요한 환경 변수는 없습니다.

## 데이터 저장 방식

런타임 데이터베이스와 영속 저장소를 사용하지 않습니다. HTML에서 편집한 텍스트는 브라우저 메모리에만 반영되며, 새로고침하거나 페이지를 닫으면 사라집니다. 편집 결과를 저장소 파일에 반영하는 기능도 구현되어 있지 않습니다.

## 테스트

자동화된 테스트나 테스트 실행 설정은 없습니다. 변경 후에는 로컬 정적 서버에서 다음 항목을 수동으로 확인해야 합니다.

- `index.html`과 `data.html`이 오류 없이 열리는지
- 이전·다음 버튼과 키보드 탐색이 동작하는지
- 편집 보기와 발표 보기 전환 및 전체 화면 기능이 동작하는지
- 로컬 이미지와 내부 링크가 정상적으로 표시되는지
- `data.html`의 화면 크기를 바꿨을 때 슬라이드가 뷰포트에 맞게 조정되는지

## 현재 구현 상태

- 요약 페이지와 상세 페이지는 정적 HTML 문서로 구현되어 있습니다.
- 요약 페이지는 박람회, 학교 방문, 국가별 비교 및 부록 안내를 다룹니다.
- 상세 페이지는 세션·부스 조사, 학교별 방문 가이드 및 국가별 교육 비교 자료를 묶어 제공합니다.
- 페이지의 초기 카운터 문구에는 각각 `1 / 14`, `1 / 167`이 들어 있지만, JavaScript가 로드된 뒤 실제 DOM 기준인 15장과 146장으로 갱신합니다.
- 백엔드, 사용자 인증, 외부 API 연동, 데이터베이스 및 배포 자동화는 구현되어 있지 않습니다.

## 알려진 문제 및 제한 사항

- 화면에서 수행한 텍스트 편집은 저장되지 않습니다.
- 글꼴과 아이콘 CDN이 차단되거나 오프라인이면 대체 글꼴이 사용되고 일부 아이콘이 표시되지 않을 수 있습니다.
- `index.html`은 1280×720 슬라이드를 작은 뷰포트에 맞게 축소하지 않으므로 화면 일부가 잘릴 수 있습니다.
- 상세 페이지는 하나의 큰 HTML 파일에 많은 슬라이드를 포함하므로 기기와 브라우저에 따라 초기 렌더링 비용이 커질 수 있습니다.
- `image/`의 6개 자산 중 `damstede.jpg`와 `labschool.jpg`는 현재 HTML에서 참조하지 않습니다.
- 저장소 이름에는 `2025`가 포함되지만 현재 HTML 제목과 발표 내용은 2026 글로벌 연수를 기준으로 합니다.
- 외부 공동 아카이브, GitHub 경로 및 자료에 포함된 외부 URL의 지속적인 접근 가능성은 저장소 자체에서 보장하지 않습니다.
- 조사 내용의 최신성을 자동으로 확인하거나 원본 자료와 HTML 내용을 동기화하는 기능은 없습니다.

## 포트폴리오 전환 검토

**분류: C. 정적 전시 후보**

15장 요약 자료와 146장 상세 자료가 정적 HTML로 구현되어 있어 애플리케이션 서버, 빌드 과정과 데이터베이스 없이 전시하기 적합합니다. 요약 자료를 진입 화면으로 사용하고 상세 자료를 선택적으로 탐색하게 구성하면 에듀테크 박람회와 해외 학교에 대한 조사·구성 역량을 보여 줄 수 있습니다.

공개 전에 다음 항목을 확인해야 합니다.

- 실제 브라우저에서 슬라이드 탐색, 발표 모드, 전체 화면과 반응형 동작
- 외부 링크와 Google Fonts·Font Awesome CDN의 접근 가능성
- 저장소 이름과 발표 자료의 연도 표기 통일 여부
- 비영속 화면 편집 기능을 유지할지 여부
- `raw_data/`와 이미지의 공개 범위 및 재사용 권리
- 저장소 코드·문서·자료에 적용할 라이선스

## 라이선스

이 저장소에는 라이선스 파일이 없습니다. 따라서 코드, 문서, 이미지 및 조사 자료의 사용·수정·배포 조건이 명시되어 있지 않으며, 재사용 전 저장소 소유자와 각 자료의 권리 관계를 확인해야 합니다.
